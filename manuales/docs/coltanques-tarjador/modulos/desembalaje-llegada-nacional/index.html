DESEMBALAJE (LLEGADA NACIONAL)​

Al seleccionar la opción Desembalaje (Llegada Nacional) desde el menú de Inicio, el sistema muestra la interfaz correspondiente para registrar las operaciones relacionadas con la recepción de carga proveniente del territorio nacional.

Paso 1: Módulo Desembalaje Llegada Nacional​

Paso 2: Seleccionar Contenedor​

Seleccionamos el número del contenedor por desembalar.

Paso 3: Evidencia Sugerida​

Para adjuntar la evidencia fotográfica, el aplicativo muestra un paso a paso sugerido con varias opciones disponibles. No obstante, el usuario puede seleccionar cualquiera de ellas según su preferencia.

Paso 4: Opciones Adjuntar Evidencia​

El aplicativo permite adjuntar evidencias tomando una foto desde la cámara o seleccionando una imagen desde la galería del dispositivo.

Paso 5: Tomar Foto Cámara​

Al seleccionar la opción Tomar una foto, el aplicativo abre automáticamente la cámara del dispositivo móvil, permitiendo capturar la evidencia en tiempo real para su posterior registro en el sistema.

Paso 6: Confirmar Evidencia​

Una vez tomada la fotografía, el aplicativo muestra en pantalla una vista previa de la imagen capturada. En este punto, el usuario puede confirmar la foto seleccionando el ícono de confirmación o, en caso de no estar conforme, cancelarla y repetir la captura.

Paso 7: Abrir Galería​

Al seleccionar la opción Abrir Galería, el aplicativo accede a las carpetas de imágenes almacenadas en el dispositivo móvil, permitiendo al usuario navegar entre ellas y elegir la fotografía que desea adjuntar como evidencia.

Paso 8: Seleccionar Foto de Galería​

Se debe seleccionar primero la carpeta de origen donde se encuentra almacenado el archivo de imagen y, posteriormente, elegir la fotografía que se desea anexar como evidencia en el proceso.

Paso 9: Foto a Media Carga​

Una vez cargadas las tres fotos iniciales, el sistema muestra la opción de fotografía a media carga, la cual aparece deshabilitada. Posteriormente, damos clic en el botón Empezar a contar para continuar con el proceso.

Paso 10: Formulario de Conteo​

En el formulario de conteo de desebalaje ingresamos la cantidad disponible y las averías encontradas. Es importante tener en cuenta que el número de averías no puede ser mayor a la cantidad disponible registrada.

Paso 11: Mensaje Foto a Media Carga​

Una vez se ha registrado en el formulario de conteo la mitad de la carga desembalada, se genera un mensaje modal que indica que debe tomarse la foto a media carga. Damos clic en Aceptar para continuar.

Paso 12: Opciones Evidencia Media Carga​

El aplicativo permite adjuntar evidencias tomando una foto desde la cámara o seleccionando una imagen desde la galería del dispositivo.

Paso 13: Continuar Conteo​

Una vez tomada la fotografía a media carga y verificadas todas las imágenes cargadas en el aplicativo, damos clic en el botón Continuar contando para seguir con el proceso.

Paso 14: Editar Cantidad Disponible​

Para editar una cantidad disponible en el formulario, damos clic sobre el campo que deseamos modificar y, en el modal que se despliega, seleccionamos el botón Editar.

Paso 15: Finalizar Guardar Cantidades​

Una vez completado el formulario de conteo, damos clic en el botón Guardar cantidades y, en el modal que aparece, seleccionamos Aceptar para confirmar la acción.

Paso 16: Evidencias Finales Desembalaje​

Para subir las evidencias fotográficas finales, el aplicativo muestra el paso a paso sugerido; sin embargo, se puede elegir cualquier opción. Damos clic en la primera opción para continuar.

Paso 17: Opciones Adjuntar Evidencia Final​

El aplicativo permite adjuntar evidencias tomando una foto desde la cámara o seleccionando una imagen desde la galería del dispositivo.

Paso 18: Tomar Foto Cámara Final​

Al seleccionar la opción Tomar una foto, el aplicativo abre automáticamente la cámara del dispositivo móvil, permitiendo capturar la evidencia en tiempo real para su posterior registro en el sistema.

Paso 19: Confirmar Evidencia Final​

Una vez tomada la fotografía, el aplicativo muestra en pantalla una vista previa de la imagen capturada. En este punto, el usuario puede confirmar la foto seleccionando el ícono de confirmación o, en caso de no estar conforme, cancelarla y repetir la captura.

Paso 20: Abrir Galería Final​

Al seleccionar la opción Abrir Galería, el aplicativo accede a las carpetas de imágenes almacenadas en el dispositivo móvil, permitiendo al usuario navegar entre ellas y elegir la fotografía que desea adjuntar como evidencia.

Paso 21: Seleccionar Foto de Galería Final​

Se debe seleccionar primero la carpeta de origen donde se encuentra almacenado el archivo de imagen y, posteriormente, elegir la fotografía que se desea anexar como evidencia en el proceso.

Paso 22: Finalizar Cierre de Proceso​

Para finalizar el proceso de desembalaje, damos clic en el botón Finalizar desembalaje y, en el modal que se muestra, seleccionamos Aceptar para confirmar el cierre del proceso.

Paso 23: Reporte Desembalaje PDF​

Para descargar el reporte del desembalaje, damos clic en el botón Descargar PDF. El sistema generará el documento con toda la información registrada durante el proceso.

Paso 24: Formulario Inspección Completo​

El archivo descargado contiene el formulario de inspección completo, junto con las fotografías asociadas al proceso de desembalaje realizado, sirviendo como evidencia documental del procedimiento ejecutado.

Paso 25: Formulario Inspección PDF​

El formulario incluye información clave del proceso, como el número del contenedor, el nombre del tarjador responsable y la fecha de ejecución del desembalaje, garantizando la trazabilidad y control del registro.
