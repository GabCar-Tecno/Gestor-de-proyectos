MOVIMIENTOS DE CEDI​

El módulo Movimientos CEDI permite registrar los movimientos de entrada o salida de contenedores en el Centro de Distribución (CEDI), manteniendo un control preciso sobre su estado (lleno o vacío) y su trazabilidad dentro del proceso logístico.

Paso 1: Módulo Movimientos CEDI​

Paso 2: Reconocimiento de Contenedor​

El campo destinado para ingresar el número del contenedor que será registrado en el sistema se realiza mediante toma de fotografía de la identificación del contenedor.

Paso 3: Confirmación de Foto​

Una vez tomada la fotografía, el aplicativo muestra en pantalla una vista previa de la imagen capturada. En este punto, el usuario puede confirmar la foto seleccionando el ícono de confirmación o, en caso de no estar conforme, cancelarla y repetir la captura.

Paso 4: Seleccionar Entrada / Salida​

En el campo "Seleccione Entrada / Salida", despliega la lista de opciones y elige una de las siguientes alternativas: Entrada: cuando el contenedor ingresa al CEDI. Salida: cuando el contenedor sale del CEDI.

Paso 5: Seleccionar Lleno / Vacío​

En el campo "Seleccione Lleno / Vacío", selecciona el estado actual del contenedor: Lleno: si contiene carga o mercancía. Vacío: si no contiene carga.

Paso 6: Confirmación de Guardado​

Una vez completados los campos, el usuario debe presionar el botón Guardar, con lo cual el sistema almacena la información y finaliza el proceso de registro del movimiento.
