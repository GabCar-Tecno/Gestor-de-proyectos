DASHBOARD​

Recepción y Gestión de Novedades​

Recepción y gestión de novedades: Muestra información sobre las novedades recibidas, el estado de su gestión y el porcentaje de novedades atendidas.

Disponibilidad de Estaciones de Servicio​

Disponibilidad de estaciones de servicio: Presenta el estado de las estaciones de servicio, tanto propias como de terceros, indicando aquellas que se encuentran sin novedades y las que tienen novedades registradas. Desliza el dashboard para visualizarlo.
