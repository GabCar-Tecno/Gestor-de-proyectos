INTRODUCCIÓN​

Coltanques Estimado de Combustible es una aplicación móvil desarrollada para optimizar la gestión, el control y el seguimiento del proceso de abastecimiento de combustible dentro de la operación de Coltanques. La aplicación centraliza las actividades relacionadas con la estimación de consumo, la gestión de solicitudes de tanqueo, el registro y seguimiento de novedades, así como la consulta de información operativa, permitiendo una administración más eficiente y un mejor control de los procesos.

La aplicación está diseñada para apoyar las actividades de los diferentes perfiles involucrados en la operación, proporcionando herramientas específicas de acuerdo con el rol asignado. Entre sus funcionalidades se incluyen la elaboración y consulta de estimados de combustible, la autorización y gestión de solicitudes de tanqueo, el reporte y atención de novedades, el seguimiento a las estaciones de servicio y la visualización de indicadores a través de tableros de control.

El acceso a las funcionalidades se encuentra controlado mediante perfiles de usuario, garantizando que cada rol disponga únicamente de las opciones necesarias para el desempeño de sus funciones. Esto contribuye a fortalecer la seguridad de la información, la trazabilidad de las operaciones y el cumplimiento de los procesos establecidos por la organización.

OBJETIVO​

Orientar a los usuarios en el uso de la aplicación Coltanques Estimado de Combustible, describiendo de manera clara el funcionamiento de cada uno de sus módulos, las actividades que pueden realizar según su rol y los procedimientos necesarios para ejecutar correctamente las diferentes operaciones disponibles en la aplicación.

PÚBLICO OBJETIVO​

Este manual está dirigido a los colaboradores de Coltanques que utilizan la aplicación Coltanques Estimado de Combustible como herramienta de apoyo para la gestión del proceso de abastecimiento de combustible.

Su contenido está orientado a los usuarios que, de acuerdo con el rol asignado, interactúan con las diferentes funcionalidades de la aplicación para consultar información, gestionar solicitudes, atender novedades y realizar el seguimiento de las actividades relacionadas con la operación. En las siguientes secciones se describen los perfiles de usuario y los módulos disponibles para cada uno de ellos.

Está orientado especialmente a:

Coordinador de Combustibles​

El rol de Coordinador de Combustibles tiene acceso a los módulos necesarios para gestionar el proceso de abastecimiento de combustible, realizar el seguimiento de las solicitudes de tanqueo y atender las novedades que se presenten durante la operación. De acuerdo con los permisos asignados, podrá acceder a las siguientes funcionalidades:

  • Estimado de Combustible: Permite consultar el estimado de combustible asociado a un manifiesto de viaje, visualizando información como la estación de servicio asignada, la cantidad estimada y los datos relacionados con el proceso de abastecimiento.
  • Autorizar Solicitudes de Tanqueo: Permite consultar las solicitudes de tanqueo pendientes y las ya gestionadas. Además, el coordinador puede aprobar o rechazar las solicitudes, registrando la decisión correspondiente para dar continuidad al proceso.
  • Reportar Errores en Registro: Permite registrar y reportar errores o inconsistencias identificadas durante la operación, asociándolos a una agencia y a un manifiesto. También es posible clasificar la novedad y adjuntar información de soporte cuando sea necesario.
  • Respuestas: Permite consultar el estado de gestión de los errores reportados, visualizar las respuestas registradas por el área responsable y conocer el usuario que atendió cada caso.
  • EDS con Novedad: Permite consultar las novedades registradas en las estaciones de servicio (EDS), tanto las que se encuentran pendientes de atención como aquellas que ya fueron gestionadas, facilitando el seguimiento y control de cada registro.

Jefe de Combustibles​

El rol de Jefe de Combustibles tiene acceso a las funcionalidades necesarias para supervisar y gestionar el proceso de abastecimiento de combustible, realizar el seguimiento de las solicitudes de tanqueo y controlar las novedades presentadas durante la operación. De acuerdo con los permisos asignados, podrá acceder a los siguientes módulos:

  • Estimado de Combustible: Permite consultar el estimado de combustible asociado a un manifiesto de viaje, visualizando información como la estación de servicio asignada, la cantidad estimada y los datos relacionados con el proceso de abastecimiento.
  • Autorizar Solicitudes de Tanqueo: Permite consultar las solicitudes de tanqueo pendientes y las ya gestionadas. Además, el coordinador puede aprobar o rechazar las solicitudes, registrando la decisión correspondiente para dar continuidad al proceso.
  • Reportar Errores en Registro: Permite registrar y reportar errores o inconsistencias identificadas durante la operación, asociándolos a una agencia y a un manifiesto. También es posible clasificar la novedad y adjuntar información de soporte cuando sea necesario.
  • Respuestas: Permite consultar el estado de gestión de los errores reportados, visualizar las respuestas registradas por el área responsable y conocer el usuario que atendió cada caso.
  • EDS con Novedad: Permite consultar las novedades registradas en las estaciones de servicio (EDS), tanto las que se encuentran pendientes de atención como aquellas que ya fueron gestionadas, facilitando el seguimiento y control de cada registro.

Administrador de Estación de Servicio​

El rol de Administrador de Estación de Servicio tiene acceso a las funcionalidades necesarias para gestionar las novedades y solicitudes relacionadas con la operación de la estación de servicio, así como consultar indicadores que apoyan el seguimiento de la gestión. De acuerdo con los permisos asignados, podrá acceder a los siguientes módulos:

  • Dashboard: Permite consultar los tableros de control con los principales indicadores de la operación, facilitando el seguimiento de la gestión de novedades, solicitudes y el estado de las estaciones de servicio.
  • Novedades en Estación de Servicio: Permite registrar, gestionar y consultar las novedades reportadas en las estaciones de servicio. Además, es posible realizar seguimiento tanto a las novedades pendientes como a las que ya han sido gestionadas.
  • Reportes de Errores en Registro: Permite consultar y gestionar los errores reportados durante la operación, visualizar su estado y realizar el seguimiento de aquellos que ya fueron atendidos.
  • Solicitudes de Tanqueo: Permite consultar las solicitudes de tanqueo pendientes de gestión y revisar el historial de las solicitudes que ya han sido procesadas, facilitando el control del proceso de abastecimiento.

Director de Compras y Almacén​

El rol de Director de Compras y Almacén tiene acceso a las funcionalidades que le permiten realizar el seguimiento de los indicadores de la operación y consultar las novedades reportadas durante el proceso de abastecimiento de combustible. De acuerdo con los permisos asignados, podrá acceder a los siguientes módulos:

  • Dashboard: Permite consultar los tableros de control con los principales indicadores de la operación, facilitando el monitoreo de la gestión de novedades y el estado general del proceso.
  • Novedades Reportadas: Permite consultar las novedades registradas durante la operación, visualizando tanto las que se encuentran pendientes de gestión como aquellas que ya han sido atendidas, junto con la información asociada a cada registro.
