INICIO​

Al seleccionar la opción Inicio en el menú de navegación, se despliega la pantalla principal de la aplicación. Desde esta vista, el usuario puede acceder a los diferentes módulos operativos, los cuales concentran las funciones esenciales para el registro, consulta y gestión de la información dentro del sistema.

Paso 1: Opción Inicio​

En el menú inferior de la vista seleccionamos la opción Inicio.

Paso 2: Pantalla Principal de Módulos​

Desde esta vista se accede a los módulos: Sincronizar, Importar, Exportación Levante y Exportación Cierre.

SINCRONIZAR​

Al seleccionar el módulo Sincronizar, se despliegan las diferentes opciones disponibles para mantener actualizada la información del dispositivo con la base de datos del sistema.

Opciones del Módulo Sincronizar​

Limpiar Base de Datos​

Al seleccionar la opción "Limpiar base de datos", el sistema elimina la información almacenada localmente en el dispositivo, asegurando que los datos estén actualizados antes de una nueva sincronización. Una vez completada la acción, se muestra un mensaje de confirmación indicando que los datos fueron eliminados exitosamente.

Limpiar Registros Inspección Offline​

Al seleccionar la opción "Limpiar registros inspección offline", el sistema elimina los datos de inspecciones realizadas en modo offline que permanecen almacenados localmente en el dispositivo. Una vez completada la acción, se muestra un mensaje de confirmación.

Sincronizar Recepción Importaciones Levante​

Al seleccionar la opción "Sincronizar recepción importaciones LEVANTE", el sistema inicia la actualización de los registros correspondientes. Durante la ejecución, se muestran modales informativos que confirman el inicio y avance de la sincronización.

Sincronizar Recepción Exportaciones Levante​

Al seleccionar la opción "Sincronizar recepción exportaciones LEVANTE", el sistema inicia el proceso de sincronización correspondiente. Durante la ejecución, se muestran modales informativos que notifican el avance.

Sincronizar Recepción Exportaciones Cierre​

Al seleccionar la opción "Sincronizar recepción exportaciones CIERRE", el sistema sincroniza los registros de exportaciones en etapa de Cierre. Durante la ejecución, se muestran modales informativos.

Sincronizar Datos Base para la Inspección​

Al seleccionar la opción "Sincronizar datos base para la inspección", el sistema sincroniza los registros necesarios. Durante la ejecución, se muestran modales informativos de avance.
