ACCESO AL APLICATIVO​

Para acceder a la aplicación web, el usuario debe de hacer uso de sus credenciales de acceso (usuario y contraseña).

RECUPERACIÓN DE CONTRASEÑA​

Para solicitar la recuperación de contraseña, haz clic en la opción “¿Olvidaste la contraseña?”.

Para recuperar tu contraseña, haz clic en "Aceptar" y el sistema enviará automáticamente un código de verificación al correo electrónico registrado (revisa tu bandeja de entrada y, si no lo encuentras, verifica la carpeta de spam).

Para completar el proceso de recuperación, ingresa el código que recibiste en tu correo electrónico y haz clic en "Continuar" para validar tu identidad. Si tienes problemas con el código, verifica que lo hayas copiado correctamente (sin espacios adicionales)

Para actualizar tu contraseña, ingresa una nueva contraseña segura y confírmela escribiéndola nuevamente para verificar que coincidan, luego haz clic en "Guardar" para finalizar.

CERRAR SESIÓN​

Para cerrar sesión da clic en el icono de salir ubicado en el panel del menú de navegación.

El sistema mostrará una ventana de confirmación. Haga clic en Aceptar para cerrar la sesión o en Cancelar si desea permanecer en la aplicación.
